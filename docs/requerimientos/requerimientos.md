# Requerimientos del sistema

## Funcionales
- RF1: El sistema permite registrar usuarios e iniciar sesión.
- RF2: El usuario puede crear, consultar, editar y eliminar registros (CRUD) del módulo principal.
- RF3: El sistema genera reportes o listados filtrables por fecha o categoría.

## No funcionales
- RNF1: Las consultas responden en menos de 3 segundos.
- RNF2: Las contraseñas se almacenan cifradas y el acceso se controla por roles.
- RNF3: Funciona en navegadores modernos y en celulares (diseño responsive).
