# Plan por etapas

| Etapa | Actividades | Duración |
|---|---|---|
| 1. Análisis | Requerimientos, alcance | Semana 1 |
| 2. Diseño | Arquitectura, base de datos, interfaces | Semana 2 |
| 3. Desarrollo | Backend, frontend, integración | Semanas 3-5 |
| 4. Pruebas | Pruebas funcionales y corrección de errores | Semana 6 |
| 5. Despliegue | Publicación y documentación | Semana 7 |

# Matriz de riesgos

| Riesgo | Probabilidad | Impacto | Mitigación |
|---|---|---|---|
| Retraso en las entregas | Media | Alto | Seguimiento semanal del plan |
| Pérdida de código | Baja | Alto | Usar Git/GitHub |
| Conflictos entre integrantes | Media | Medio | Ramas por persona y reuniones cortas |
| Fallos de seguridad | Media | Alto | Validar datos y cifrar contraseñas |
| Falta de conocimiento técnico | Alta | Medio | Capacitación y documentación |
